# LAB / SPACE — Вартові неба × Re:Fly

Редагований адаптивний сайт-презентація двох гуртків. Створений на HTML, CSS і чистому JavaScript.

## Як запустити
1. Розпакуйте архів у папку.
2. Відкрийте `index.html` у браузері.
3. Для зручного редагування коду відкрийте папку у Visual Studio Code.

Інтернет потрібен лише для завантаження шрифту Manrope. Без інтернету сайт також працюватиме із системним шрифтом.

## Як редагувати
- Натисніть **«Редагувати»** у верхній панелі.
- Натисніть на текст, який хочете змінити, і відредагуйте його.
- Натисніть **«Зберегти зміни»**. Зміни зберігаються у localStorage цього браузера.
- Щоб додати картку проєкту, у режимі редагування натисніть **«Додати проєкт»**.
- Для зміни структури, стилів та функцій редагуйте `index.html`, `styles.css`, `script.js`.

## Важливо про збереження
Режим редагування зберігає вміст у браузері на конкретному пристрої. Це не публікує зміни на сайті для інших відвідувачів. Щоб оновити опубліковану версію, змініть файли проєкту та повторно завантажте їх на хостинг.

## Що варто персоналізувати перед публікацією
- Замінити демонстраційні описи на фактичні результати гуртків.
- Додати справжні фотографії та роботи учнів.
- Замінити `your-email@example.com` у `index.html` на контактну адресу.
- За потреби додати посилання на соціальні мережі та QR-код.

## Структура
- `index.html` — сторінка та її зміст.
- `styles.css` — оформлення, кольори, адаптивність.
- `script.js` — фільтри, режим редагування та локальне збереження.

## Нові навчальні сторінки
- `pages/budova.html` — інтерактивна сторінка «Будова FPV-дрона» з авторською SVG-схемою-блюпрінтом та картками компонентів.
- `pages/trajectory.html` — інтерактивний навчальний матеріал «Траєкторія польоту» з перемиканням типів траєкторій, поясненнями чинників та чеклістом відповідального планування.
- `pages/lesson-pages.css` — стилі навчальних сторінок.
- `pages/lesson-pages.js` — інтерактивність компонентів, вкладок і карток.
- `assets/fpv-blueprint.svg` — векторний блюпрінт, який можна редагувати у векторному редакторі або кодом.

На головній сторінці картки «Будова FPV-дрона» та «Траєкторія польоту» ведуть на відповідні сторінки.


## Нові сторінки гуртка Re:Fly
- `pages/poster.html` — навчальна сторінка «Плакатна композиція»: принципи композиції, інтерактивний вибір теми та палітри, чекліст самоперевірки.
- `pages/identity.html` — навчальна сторінка «Візуальна айдентика»: логотип, палітра, типографіка, графічна мова, приклади застосування стилю.
- `pages/refly-pages.css` та `pages/refly-pages.js` — стилі й інтерактивність двох сторінок.
- `assets/refly-poster-composition.png` — авторська візуальна робота-приклад для сторінки плакатної композиції.

На головній сторінці в картках Re:Fly доступні переходи до обох нових матеріалів.


### Карусель робіт і досягнень
На головній сторінці блок «Кожен крок — це досягнення» оформлено як адаптивну карусель із трьома візуальними роботами. Додані зображення зберігаються в `assets/achievement-space.jpeg`, `assets/achievement-city.png` та `assets/achievement-river.png`. Перемикання працює кнопками, індикаторами та свайпом на сенсорних екранах.


## Сторінка автора
- `pages/author.html` — окрема сторінка автора освітнього простору з коротким представленням, принципами роботи та посиланнями на Instagram і Telegram.
- `pages/author.css` — адаптивні стилі сторінки автора.
- `assets/author-artwork.png` — авторська геометрична ілюстрація для обкладинки сторінки.
- У головній навігації та футері додано перехід на сторінку автора.
