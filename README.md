# LAB / SPACE — DroneXDesign

Світла адаптивна навчальна платформа.

- `index.html` — головна сторінка.
- `drone.html` — простір «Вартові неба» з уроками: Будова дрона, Траєкторія польоту, Політ у симуляторі.
- `refly.html` — простір Re:Fly з уроками: Колористика, Світ шрифтів, Композиція та плакат.
- `lessons/` — шість окремих навчальних сторінок з теорією, інтерактивними вправами та тестами.

Для публікації завантажте весь вміст архіву в корінь GitHub-репозиторію. У GitHub Pages виберіть `main` та `/ (root)`. Збірка не потрібна.
